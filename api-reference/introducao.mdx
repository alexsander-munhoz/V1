A API REST da Brudam TMS permite que você integre seus sistemas existentes — ERP, e-commerce, WMS — à plataforma Brudam, criando entregas, emitindo CT-e, rastreando remessas e gerenciando dados financeiros de forma programática, sem depender de interfaces manuais.

## Base URL

Todas as requisições devem ser enviadas para o endpoint base abaixo. Inclua sempre o prefixo de versão no caminho.

```
https://api.brudam.com.br/v1
```

## Formato

A API segue convenções padronizadas para garantir consistência entre todos os endpoints:

- **Corpo das requisições e respostas:** JSON — sempre envie o cabeçalho `Content-Type: application/json`
- **Datas:** ISO 8601 no formato `YYYY-MM-DDTHH:MM:SSZ` (UTC)
- **Valores monetários:** Reais brasileiros (BRL), representados como números decimais (ex: `199.90`)
- **Identificadores:** UUIDs no formato string (ex: `"3fa85f64-5717-4562-b3fc-2c963f66afa6"`)

## Versionamento

A versão atual da API é **v1**, indicada diretamente no caminho da URL (`/v1/...`). Quando mudanças incompatíveis (*breaking changes*) forem introduzidas, uma nova versão (ex: `v2`) será disponibilizada com antecedência mínima de **90 dias**. Você continuará podendo usar a versão anterior durante o período de transição.

## Limites de requisições (Rate Limiting)

Cada plano possui um limite de requisições por minuto. Se você ultrapassar esse limite, a API retornará o status HTTP **429 Too Many Requests** com o cabeçalho `Retry-After` indicando quantos segundos aguardar antes de tentar novamente.

| Plano | Requisições por minuto |
|---|---|
| Essencial | 60 |
| Profissional | 300 |
| Enterprise | 1.000 |

## Disponibilidade

A API Brudam TMS conta com SLA de **99% de disponibilidade**. Você pode acompanhar o status em tempo real, incluindo incidentes e manutenções programadas, na página:

**[status.brudam.com.br](https://status.brudam.com.br)**
