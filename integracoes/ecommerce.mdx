O Brudam TMS conecta-se a plataformas de e-commerce e marketplaces para que os pedidos realizados pelos seus clientes remetentes fluam diretamente para o TMS — gerando CT-e, rastreamento e confirmação de entrega de forma totalmente automática.

## Como funciona

O fluxo integrado entre o e-commerce e o Brudam TMS funciona da seguinte forma:

1. **Pedido realizado** — O comprador finaliza o pedido na plataforma de marketplace ou e-commerce.
2. **Pedido chega ao Brudam** — As informações do pedido são enviadas automaticamente para o Brudam TMS via API ou webhook.
3. **CT-e gerado** — O Brudam emite o Conhecimento de Transporte Eletrônico (CT-e) vinculado ao pedido, sem nenhuma intervenção manual.
4. **Link de rastreamento enviado** — Um link de rastreamento é gerado e enviado automaticamente ao comprador para acompanhamento em tempo real.
5. **Entrega confirmada** — Ao concluir a entrega, o Brudam retorna a confirmação ao marketplace ou plataforma de e-commerce, atualizando o status do pedido automaticamente.

## Integração via API

Para integrar o Brudam TMS a qualquer plataforma de e-commerce — inclusive soluções proprietárias ou personalizadas — utilize a **Brudam REST API**. Os principais endpoints para operações de e-commerce são:

| Endpoint | Descrição |
|---|---|
| `POST /v1/coletas` | Cria um pedido de coleta a partir do pedido do e-commerce |
| `GET /v1/rastreamento/{id}` | Retorna o status de rastreamento de uma encomenda |

<Card title="Referência da API Brudam" icon="code" href="/api-reference/introducao">
  Consulte a documentação completa dos endpoints, autenticação e exemplos de integração.
</Card>

## Webhooks para atualizações em tempo real

Configure webhooks no Brudam para que os eventos de entrega sejam enviados automaticamente à sua plataforma de e-commerce — sem necessidade de consultar a API repetidamente. Os eventos disponíveis são:

| Evento | Descrição |
|---|---|
| `coleta_confirmada` | Disparado quando a coleta da encomenda é confirmada pelo motorista |
| `entrega_confirmada` | Disparado quando a entrega ao destinatário é registrada com sucesso |
| `insucesso_entrega` | Disparado quando há uma tentativa de entrega sem sucesso |

Para configurar os webhooks e definir a URL de destino das notificações, consulte o guia de integrações:

<Card title="Configurar Webhooks" icon="webhook" href="/conceitos/integracoes">
  Veja como cadastrar endpoints de webhook e testar o recebimento de eventos no Brudam TMS.
</Card>

<Tip>
  Use o webhook `entrega_confirmada` para atualizar o status do pedido na sua plataforma de e-commerce automaticamente, sem precisar fazer polling na API. Isso reduz a latência das atualizações e o número de requisições desnecessárias.
</Tip>
