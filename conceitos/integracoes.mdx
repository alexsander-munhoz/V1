Seja um ERP corporativo, um marketplace de e-commerce ou um rastreador de frota, a integração é configurada de forma centralizada no painel.

## API Aberta

O Brudam TMS disponibiliza uma API REST completa para integrações customizadas com sistemas que não possuem conector nativo. A API segue os padrões modernos de desenvolvimento e é documentada de forma interativa.

**Características da API:**

- **Autenticação via JWT:** cada requisição é autenticada com um token seguro gerado nas configurações da conta. Tokens têm escopo configurável por recurso (leitura, escrita, webhooks).
- **Endpoints principais:** emissão de CT-e, consulta de entregas, cadastro de clientes, gerenciamento de tabelas de frete, consulta financeira e muito mais.
- **Formato JSON:** todas as requisições e respostas utilizam JSON, com esquemas documentados e exemplos prontos para uso.
- **Sandbox de testes:** ambiente isolado disponível para desenvolvedores validarem integrações sem afetar dados de produção.

Para a referência completa de endpoints, parâmetros e exemplos de código, acesse a [documentação da API](/api-reference/introducao).

## Webhooks

Além de consultas ativas via API, o Brudam TMS pode enviar notificações automáticas para os seus sistemas sempre que eventos relevantes ocorrerem na plataforma — sem necessidade de polling.

**Eventos disponíveis para webhook:**

| Evento | Descrição |
|---|---|
| `cte.autorizado` | CT-e foi autorizado pelo SEFAZ com sucesso |
| `cte.cancelado` | CT-e foi cancelado e o evento registrado no SEFAZ |
| `entrega.confirmada` | Motorista confirmou a entrega com POD (foto/assinatura) |
| `coleta.confirmada` | Motorista confirmou a coleta no endereço do remetente |

Para cada webhook, você configura a URL de destino, o segredo de validação (HMAC) e os eventos que deseja receber. O Brudam TMS realiza até **3 tentativas automáticas** em caso de falha na entrega da notificação, com backoff exponencial.

<Note>
  A API Aberta e os webhooks estão disponíveis nos planos **Profissional** e **Enterprise**. Para comparar planos e verificar os recursos incluídos em cada um, acesse [Planos e Preços](/planos-e-precos).
</Note>
