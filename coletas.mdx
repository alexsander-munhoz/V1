  --data '{

**`200`** — Retorno sucesso

```json
{
  "message":"OK",
  "status":1,
  "data":[
    {
      "cAut":807060,
      "status":1,
      "message":"Documento gerado no sistema",
      "id": "5165"
    },
    {
      "cAut":807060,
      "status":1,
      "message":"Documento gerado no sistema",
      "id":"5165"
    }
  ]

```

**`400`** — Retorno erro preenchimento

```json
{
  "message":"Erro nos dados enviados",
  "status":0,
  "data":[
    "O campo 'Documentos->[0]->Coleta->Toma' deve conter um dos seguintes valores: 0,1,2,3,4"
  ]
}
```
