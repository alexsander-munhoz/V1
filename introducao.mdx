A API Brudam TMS é **multi-tenant por subdomínio**: cada transportadora acessa por um
domínio próprio, no formato `<seuidentificador>.brudam.com.br`. Por exemplo:

| Cliente | Domínio da API |
|---|---|
| Transportadora Um | `https://transportadoraum.brudam.com.br/api/v1` |
| Transportadora Dois | `https://transportadoradois.brudam.com.br/api/v1` |

<Warning>
As credenciais (usuário/senha ou token) são específicas de cada subdomínio. Um token
gerado em `transportadoraum.brudam.com.br` **não funciona** em
`transportadoradois.brudam.com.br` — são ambientes isolados por cliente.
</Warning>

Nas páginas de referência desta documentação, o seletor de servidor (no topo de cada
endpoint) pede o seu identificador de cliente para montar a URL correta automaticamente
antes de testar.
