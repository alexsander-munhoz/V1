Esta página guia você pelos passos essenciais para realizar sua primeira chamada à API do Brudam TMS. Em menos de 10 minutos, você estará autenticado e consultando dados reais da sua operação de transporte.

## Passo a passo

<Steps>
  <Step title="Criar conta">
    Acesse [app.brudam.com.br](https://app.brudam.com.br) e crie sua conta gratuitamente. Você tem **7 dias de teste grátis** sem precisar cadastrar cartão de crédito — basta preencher os dados básicos da sua transportadora e começar a explorar.
  </Step>

  <Step title="Gerar token de acesso">
    Após fazer login, navegue até **Configurações → Integrações → API Keys**. Clique em **Gerar nova chave**, dê um nome descritivo (por exemplo, `integração-erp`) e copie o **Bearer token** exibido.

    <Warning>
      Guarde seu token em um local seguro. Por questões de segurança, ele não poderá ser visualizado novamente após fechar a tela de geração.
    </Warning>
  </Step>

  <Step title="Fazer primeira requisição">
    Com o token em mãos, execute o comando abaixo no seu terminal para listar as entregas da sua operação:

    ```bash
    curl -X GET https://api.brudam.com.br/v1/entregas \
      -H "Authorization: Bearer SEU_TOKEN_AQUI" \
      -H "Content-Type: application/json"
    ```

    Substitua `SEU_TOKEN_AQUI` pelo token copiado na etapa anterior.
  </Step>

  <Step title="Interpretar a resposta">
    Uma resposta bem-sucedida retorna um objeto JSON com a lista de entregas, o total de registros e a página atual. Veja um exemplo:

    ```json
    {
      "data": [
        {
          "id": "f1e7be5c-1234-4abc-8def-000000000001",
          "status": "em_transito",
          "destinatario": "Empresa ABC Ltda",
          "volumes": 3,
          "previsao_entrega": "2025-08-15T18:00:00Z"
        }
      ],
      "total": 1,
      "pagina": 1
    }
    ```

    O campo `status` indica a situação atual da entrega. Os valores possíveis incluem `em_transito`, `entregue`, `pendente` e `ocorrencia`. Use o campo `id` para consultas e atualizações posteriores.
  </Step>
</Steps>

<Note>
  Todas as requisições à API Brudam devem ser feitas via **HTTPS**. Requisições sem o cabeçalho `Authorization` com o Bearer token válido serão rejeitadas com o código `401 Unauthorized`.
</Note>

<Tip>
  Quer explorar todos os endpoints disponíveis, parâmetros de filtragem e modelos de resposta? Consulte a [documentação completa da API](/api-reference/introducao).
</Tip>
